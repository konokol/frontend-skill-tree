    集合与标准函数（P1）

    1. Sequence 和 Iterable 区别？
    2. Iterable 立即求值生成中间集合；Sequence 惰性逐元素。
    3. fold 和 reduce 区别？
    4. fold 有初始值；reduce 无初始值，空集合抛异常。
    5. associate 和 associateBy 区别？
    6. associate 自定义键值对；associateBy 指定 key，value 是元素本身。
    7. groupBy 返回什么？
    8. Map<K, List>，按 key 分组。
    9. let/run/with/apply/also 速记？
    10. let it 返回；run this 返回；with this 返回；apply this 自身；also it 自身。

    Java 互操作（P1）

    1. Kotlin 调 Java 平台类型风险？
    2. 可空性未知，当非空用可能 NPE。
    3. Java 调 Kotlin 非空参数传 null？
    4. 编译通过，运行时抛 NPE（Intrinsics.checkNotNullParameter）。
    5. Kotlin 可空性如何传给 Java？
    6. 生成 @Nullable/@NotNull 注解，Java IDE 可见但不强制。
    7. @JvmOverloads 作用？
    8. 默认参数生成重载方法，方便 Java 调用。
    9. @Throws 作用？
    10. 声明受检异常，Java 强制捕获。
    11. @JvmName 作用？
    12. 修改生成的类名、方法名、getter/setter 名。
    13. @JvmSuppressWildcards 作用？
    14. 抑制泛型通配符生成。
    15. fun interface 作用？
    16. 让 Kotlin 接口支持 SAM 转换，Java 可用 lambda。

    反射、KSP、编译期（P2）

    1. Kotlin 反射和 Java 反射区别？
    2. Kotlin 反射需 kotlin-reflect，支持可空性、默认参数；性能更低。
    3. KSP 和 KAPT 区别？
    4. KSP 直接分析 Kotlin 不生成存根，快 2-5 倍；KAPT 生成 Java 存根。
    5. K2 编译器是什么？
    6. Kotlin 2.0 新编译器，前端重写，性能更好。
    7. value class 编译后字节码？
    8. 多数场景内联为底层类型，方法名修饰。
    9. inline 函数字节码？
    10. 函数体展开到调用处，lambda 内联，无对象分配。

    Compose (P1)

    1. 声明式 UI 和命令式区别？
    2. 声明式描述状态对应 UI，状态变化重组；命令式手动更新 View。
    3. 重组是什么？
    4. 状态变化时重新执行 Composable，只更新变化部分。
    5. remember 和 rememberSaveable 区别？
    6. remember 配置变更丢失；rememberSaveable 保存到 Bundle 恢复。
    7. derivedStateOf 作用？
    8. 从其他状态派生，减少重组。
    9. LaunchedEffect、DisposableEffect、SideEffect 区别？
    10. LaunchedEffect 启动协程 key 变化重启；DisposableEffect 清理；SideEffect 每次重组后执行。
