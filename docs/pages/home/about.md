# 关于

## 项目简介

**客户端知识图谱**（frontend-skill-tree）是一份面向客户端 / 大前端工程师的体系化学习路线与知识沉淀。

从客户端视角梳理大前端能力边界：以 Android / Java / Kotlin 为核心，向外延伸到跨平台、Web 前端基础、计算机科学理论基础，以及面试与工程实践。目标是把碎片化知识点串成可迁移的技能树，方便按需点亮、长期复盘。

在线阅读：[客户端工程师技能树](https://konokol.github.io/frontend-skill-tree/)

## 覆盖范围

项目主要覆盖以下知识点：

- **Java**：语言基础、并发、集合、IO、JVM、设计模式与新特性
- **Android**：基础组件、性能优化、架构、三方框架、Framework 与工程工具
- **Kotlin**：语法与惯用法、协程、Flow 等
- **跨平台**：Flutter、React Native、小程序等
- **前端基础**：Web 前端常见知识点
- **CS 基础**：计算机基础、操作系统、网络、算法与数据结构
- **面试**：Java / Kotlin / Android 面试向整理

更细的学习路径见 [概述](../../index.md)，外部资料见 [学习资料](ref.md)。

## 使用方式

- **在线浏览**：访问 GitHub Pages 站点即可检索与阅读。
- **本地预览**：在仓库根目录安装依赖后执行 `mkdocs serve`（环境初始化可参考 `scripts/README.md`）。
- **部署**：使用 `mkdocs gh-deploy` 发布到 GitHub Pages。

本仓库基于 [MkDocs](https://www.mkdocs.org/) 构建，主题与插件配置见根目录 `mkdocs.yml`。
